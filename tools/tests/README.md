# 自動テスト（Playwright）

ゲームが「うまく操作すればクリアできる」かを調べるためのスクリプトです。
`game/index.html` を開いて、ゲームの中の `window.__game` を使って動かします。

| ファイル | 調べること |
|---|---|
| `audit.js` | すべての「わな」（トゲの柱・電気の門・扉・雷）に、安全に通れる時間が十分あるか |
| `timebot.js <ステージ番号> '[[飛ばす始まり,終わり]]' walk` | **むてきなし**で、わなのタイミングを待ちながらゴールまで行けるか（敵は外す） |
| `waterbot.js 13` | 泳ぐステージ（4-2）を、電気の門を待ちながら通れるか |
| `bridge.js '<設定JSON>'` | 雲をふんで穴をわたる場所が、ふつうのジャンプでわたれるか |
| `story.js` | ボスをたおしたあとの会話・幕の終わり・THE END までの流れ |

ステージ番号：1-1=0, 1-2=1, …（1ワールドにつき 4 つ：x-1, x-2, x-3, x-BOSS）
