# ミスターポストマン（全7章）

タイトル → プロローグ（会話）→ 1-1 → ゴール → ステージ選択（マップ）の流れで遊べます。
進み具合はブラウザに自動でセーブされ、タイトルの CONTINUE から続きができます。

ワールド1 はじまりの草原島：1-1 草原 / 1-2 森（パタクモ）/ 1-3 夕日の丘（動く足場）/ ボス 大ガエル ゲコドン
ワールド2 カラカラ砂丘島：2-1 さばく（流砂・スナモグラ）/ 2-2 いせき / 2-3 夕ぐれのオアシス / ボス 砂ムカデ ザラザラ
ワールド3 ツララ雪原島：3-1 ゆきの原っぱ（すべる氷・ユキコロ）/ 3-2 こおりのどうくつ（つらら）/ 3-3 オーロラの丘 / ボス 雪だるま将軍
ワールド4 シズク海底島（むずかしめ）：4-1 しおかぜの海岸（くずれる足場・トゲの柱・雲をふんでわたる）/ 4-2 しんかいの森（泳ぐ・電気の門）/ 4-3 さんごしょうの灯台 / ボス 大ダコ ヌルリン
ワールド5 クモリ城：5-1 雲の城門（雷・扉）/ 5-2 城の中（ベルトコンベア・回る足場）/ 5-3 城の屋上（向かい風）/ ボス クモリ男爵
ワールド6 歯車の時計島：6-1 歯車の街 / 6-2 時計塔の中 / 6-3 時計島の灯台 / ボス ギアゴーレム
ワールド7 時の灯台：7-1 時の回廊 / 7-2 さかさ時計の塔 / 7-3 時の灯台 / ボス 時の番人 トキモリ → エンディング

各ステージには時間制限があり、のこり50秒になると曲が速くなります。
各ステージに「ヒカリのかけら」が3つかくれています。

ブラウザで `index.html` を開くと遊べます（スマホは横向き）。

| 操作 | スマホ | PC |
|---|---|---|
| 左右に歩く | ◀ ▶ | ← → / A D |
| ジャンプ（長押しで高く） | JUMP | Space / ↑ / Z |
| ダッシュ切りかえ（1回押すとON・もう1回でOFF。速く高く跳べる） | DASH | Shift / X |
| 空中ブレーキ | 空中で反対向きの◀▶ | ← → |
| 光の玉を投げる（ランタンを持っているときだけ） | FIRE | C |
| 一時停止 | 右上の ⏸ | Esc / P |

ファイル構成
- `index.html` … 画面とボタン
- `style.css` … 見た目（ボタン・表示）
- `sprites.js` … ドット絵データ
- `audio.js` … 効果音とBGM（Web Audioで作るファミコン風の音。曲はオリジナル）
- `main.js` … ゲームの動き（物理・当たり判定・描画）

## オフラインで遊ぶ（飛行機の中など）
`game` フォルダを https のサーバー（GitHub Pages など）に置くと、**一度ひらけば、インターネットがなくても遊べます**
（`sw.js` がゲームのファイルを保存します）。iPhoneでは Safari の共有ボタン →「ホーム画面に追加」でアプリのように使えます。
GitHub Pages への公開は `.github/workflows/pages.yml` が自動で行います（Settings → Pages → Source を「GitHub Actions」にする）。
