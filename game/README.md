# ミスターポストマン（試作 Step 1.1）

ブラウザで `index.html` を開くと遊べます（スマホは横向き）。

| 操作 | スマホ | PC |
|---|---|---|
| 左右に歩く | ◀ ▶ | ← → / A D |
| ジャンプ（長押しで高く） | JUMP | Space / ↑ / Z |
| ダッシュ（押している間・速く高く跳べる） | DASH | Shift / X |
| 一時停止 | 右上の ⏸ | Esc / P |

ファイル構成
- `index.html` … 画面とボタン
- `style.css` … 見た目（ボタン・表示）
- `sprites.js` … ドット絵データ
- `main.js` … ゲームの動き（物理・当たり判定・描画）
